# NexaHub

NexaHub is a modern full-stack web application built using the MERN stack.

It provides a clean and responsive platform with authentication, user management, content management, and an interactive dashboard.

## 🛠️ Tech Stack

### Frontend

- React.js
- React Router
- Vite
- Material UI
- Axios
- React Hook Form
- JavaScript

### Backend

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcrypt
- Multer

## ✨ Features

- User authentication
- JWT-based authorization
- Role-based access
- Responsive dashboard
- User profile management
- Content management
- Task management
- Product management
- Image/file upload
- Admin dashboard
- Secure API endpoints
- Responsive UI
